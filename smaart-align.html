Time-Alignment Rack Console

d&b rig · Mains + Subs + Front Fills · delays applied in R1 · alignment only

THE RULE: delay the speaker that arrives FIRST.
Core move you'll repeat: Find = measure arrival → Insert = lock Smaart's time to it (makes phase readable).
1

Setup check

▾
✓
TM1 → EVO4 in 1; reference → EVO4 in 2; +48V ON.
✓
Avantis Signal Gen → Pink Noise → to Mains/Subs/Fills and one spare matrix = your reference back to in 2.
✓
Smaart: Options→Audio I/O = EVO4, 48k. TF: Meas = MIC (in1), Ref = REF (in2).
✓
Gains: both meters −18 to −12 dBFS, green, no clip.
✓
R1 delay unit = ms Extras→Options→Project.
✓
Mic on a stand, ear height, on-axis. Never handheld — your hand wrecks the data.
Phantom gotchaThe EVO4's 48V feeds both inputs. Fine for the mic; a balanced console output tolerates it. If the reference distorts/thumps → use a DI or a no-phantom path.
2

Prove the data first

▾
✓
Solo one Main. Find → Insert.
✓
Coherence high & solid in your band? If hashy: more level, more averaging, mic closer/on-axis, off reflections. Don't align on bad data.
3

Subs → Mains

▾
✓
Mic where both main & sub have energy.
✓
Solo Main: Find → Insert, then capture the trace (target = MAIN).
✓
Leave delay set. Solo Sub, Find — that's the gap. Add delay in R1 to the earlier one (shorter Find #).
✓
Fine-tune on phase: in the crossover overlap (~80–100 Hz, mags within 10 dB), nudge R1 delay until the sub's phase sits on top of MAIN's.
✓
Unmute both → want a summation bump, not a dip.
Traces parallel but ~180° apart?Polarity, not delay. Flip sub polarity in R1, re-check. Delay can't fix a flip.
4

Front Fills → Mains (delta trick)

▾
✓
Mic at a front seat the fill covers, on-axis.
✓
Solo Main: Find → Insert.
✓
Solo Fill (leave delay set): Find. The delta = delay to add to the fill.
✓
Type that into the Fill channel delay in R1.
✓
Re-Find the fill → delta should be ≈ 0 = aligned.
NoteFills are almost always early → they get delayed to wait for the mains. Multiple fills = measure & match each at the seat it serves.
5

Verify & hand off

▾
✓
Unmute all. Check middle / side / front row.
✓
Self-test: muting one side of a pair should make it drop. Gets louder? They were cancelling — realign.
✓
Spot-check the opposite L/R side matches.
✓
Log every delay below, save R1 project, screenshot Smaart.
✓
Turn OFF the Avantis pink noise before handoff.

If it fights you

▾
No trace / no signal
EVO4 selected? Inputs assigned? Phantom on? Pink routed & audible? Meters moving?
One side reads, other flat
Mic/ref swapped, or a gain is down. Verify which input is which.
Low coherence / hashy
More level, more averaging, mic closer/on-axis, off reflections.
Find won't lock / jumps
Solo one system only; raise level/averaging. Long delays → bigger FFT (time constant ≥ 3× delay).
Phase won't overlap
Polarity — flip & retry. Look only at the crossover region.
Dip at crossover
Still off, or needs a polarity flip. Redo delay, re-measure the sum.
Reference distorting
48V upsetting the tap — use a DI or a no-phantom path.
Delays sound wrong
R1 unit = ms? Editing the right amp channel?
